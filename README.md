   🎭 TenseWatcher

Теневой надзиратель — это пошаговая 2D игра на C# + MonoGame.  
Вы — испуганный оборванец, оказавшийся в ловушке. За вами охотится таинственная сущность, у которой крайне много сил.  
Чтобы сбежать, нужно собрать древние артефакты и добраться до портала, управляя уровнем тревоги.

---

  🎮 Игровой процесс

Цель: собрать 3 артефакта и выйти через портал.
Враг: ходит раз в 2 ваших хода. При касании тревога +25%.
Тревога: при 100% — поражение. Каждая ошибка приближает конец.
Световые зоны: снижают тревогу на 10%, давая короткую передышку.
Портал: открывается только после сбора всех артефактов.

Игрок и враг перемещаются по клеточному полю 10×10. Враг использует простой алгоритм преследования: сначала двигается по горизонтали, затем по вертикали, сокращая расстояние до игрока.

---

  🕹️ Управление

Стрелки (← ↑ ↓ →) — движение игрока
R — перезапуск игры (после победы или поражения)
ESC — выход из игры

---

  🧠 Архитектура

Проект построен на паттерне MVC (Model-View-Controller):
- Model (TenseWatcher.Model) — вся игровая логика: карта, движение, тревога, артефакты. Модель ничего не знает о графике.
- View + Controller (TenseWatcher.Game) — отрисовка поля, спрайтов, интерфейса и обработка нажатий клавиш.
- Tests (TenseWatcher.Tests) — модульные тесты, проверяющие корректность модели.

Такое разделение позволяет легко тестировать логику и менять графику без переписывания кода.

  🖼️ Графика

Спрайты выполнены в стиле JoJo’s Bizarre Adventure (Joseph и Cars).
